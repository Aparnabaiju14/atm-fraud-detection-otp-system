# ATM Fraud Detection and OTP Verification System

This project simulates an ATM security system that detects suspicious transactions and verifies them using OTP authentication.

## Features

- PIN authentication
- Fraud detection based on transaction amount
- OTP verification for suspicious transactions
- ATM withdrawal and balance check simulation

## Technologies Used

- Python
- Random module
- Command-line interface

## Fraud Detection Logic

Transactions above a defined threshold trigger OTP verification before completion.

## Workflow

1. User inserts card
2. User enters PIN
3. Select transaction type
4. Fraud detection check
5. OTP verification if transaction is suspicious
6. Transaction approved or blocked

## Note

## Note

This project simulates ATM security logic using a small in-memory dataset to demonstrate authentication, fraud detection rules, and OTP-based transaction verification without connecting to a real banking system.
